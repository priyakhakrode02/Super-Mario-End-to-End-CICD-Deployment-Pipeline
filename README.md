# Super Mario End-to-End CI/CD Pipeline

An end-to-end CI/CD project that automates the build, testing, and deployment of a Super Mario game using DevOps tools.

## Features
- Automated CI/CD pipeline using Jenkins.
- Configuration management using Ansible.
- Containerization using Docker.
- Application deployment using Kubernetes.
- Automated build and deployment whenever code changes.

## Tech Stack
- *CI/CD:* Jenkins
- *Containerization:* Docker
- *Configuration Management:* Ansible
- *Orchestration:* Kubernetes
- *Cloud Platform:* AWS
